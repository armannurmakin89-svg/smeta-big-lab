# Учебное портфолио

Цель проекта — создать учебное портфолио и потренироваться в работе с чистыми HTML, CSS и JavaScript.

Это статическая страница, которую можно открыть в браузере с диска: сервер, установка пакетов и сборка не нужны.

## Файлы сайта

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка страницы и её разделы |
| `styles.css` | Оформление страницы |
| `script.js` | Поведение страницы в браузере |

## Как открыть

1. Откройте `index.html` двойным щелчком — файл откроется в браузере по умолчанию.
2. Либо перетащите `index.html` в окно уже открытого браузера.

Адрес будет вида `file:///.../index.html`. Отдельный локальный сервер запускать не нужно.
