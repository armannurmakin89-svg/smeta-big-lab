# Правила для агента

Эти правила действуют в папке «Смета».

## Как работать

- Работай только в этой папке. Перед правкой сначала прочитай текущие файлы.
- Делай только ту функцию, которую просит пользователь. Уже работающие части не ломай.
- Пиши только обычные HTML, CSS и JavaScript. Не используй npm, фреймворки и внешние ресурсы. Стили подключай из `styles.css`, скрипт — из `script.js`.
- Данные пользователя остаются в браузере. Ничего не отправляй в интернет.
- Не запускай git и ничего не публикуй без явной просьбы пользователя.

## Удобство и деньги

- Подписи должны быть понятными. Поля и кнопки — не меньше 44px по высоте. Страница должна работать с клавиатуры и на телефоне.
- Деньги показывай с пробелами между тысячами: `15 000 ₸`.
- Пустые и неверные числа считай нулём. Никогда не показывай `NaN`.
