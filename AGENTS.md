# Правила для агента

Учебное портфолио — три файла: `index.html`, `styles.css`, `script.js`.

Эти правила применяются ко всему проекту.

## Как править

- Пишите только чистые HTML, CSS и JavaScript. Стили подключайте из `styles.css`, скрипт — из `script.js`.
- Сохраняйте существующие разделы страницы. Новый раздел добавляйте только по явной просьбе.
- Не подключайте пакеты, сборку, Git, внешние API и публикацию. Не добавляйте `package.json`, бандлеры, фреймворки и запросы к сети.
- Не добавляйте реальные личные данные: имя, контакты, фото, учебные документы и другие сведения о человеке. Для примеров используйте явные заглушки вроде «Имя», «Город», «example@example.com».

## После правки

В ответе перечислите изменённые файлы и что в каждом изменилось. Честно укажите, что проверено: открытие `index.html` в браузере, конкретный сценарий на странице или только просмотр кода. Если проверка в браузере не выполнялась, так и напишите.
