# Смета за 5 минут

Веб-приложение, в котором человек быстро собирает смету или коммерческое предложение и сохраняет его в PDF.

Им пользуются:

- предприниматели — чтобы отправить клиенту коммерческое предложение;
- офисные сотрудники — чтобы собрать смету закупки или список расходов для руководителя.

## Файлы

| Файл | За что отвечает |
| --- | --- |
| `index.html` | Разметка страницы: подписи, поля, кнопки и структура документа. |
| `styles.css` | Внешний вид: расположение блоков, размеры полей и кнопок, вид на телефоне. |
| `script.js` | Расчёт сумм, проверка чисел, показ денег и сохранение PDF. |

Стили подключаются из `styles.css`, логика — из `script.js`. Сторонние библиотеки и запросы в интернет не используются. Введённые данные остаются в браузере.

## Как открыть

Дважды щёлкните по файлу `index.html`. Страница откроется в браузере. Устанавливать программы и запускать сервер не нужно.

## Как проверить

Добавьте две строки:

- 2 × 15 000
- 1 × 8 000

Итог должен быть **38 000 ₸**.
